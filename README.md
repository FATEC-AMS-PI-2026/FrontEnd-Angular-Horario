# 📅 Gerenciador de Horários CPS - WEB

![Angular](https://img.shields.io/badge/Angular-20.3.0-DD0031?style=flat&logo=angular&logoColor=white&labelColor=000000)
![NPM](https://img.shields.io/badge/NPM-11.6.2-brightgreen?style=flat&logo=npm&logoColor=white&labelColor=000000)

Buscando otimizar a gestão de tempo e a visualização da infraestrutura acadêmica para alunos, professores, coordenadores e técnicos da FATEC Dom Amaury Castanho.

O projeto resolve o problema de informações descentralizadas sobre horários de aulas e disponibilidade de salas. Ele permite que o aluno configure sua grade semanal personalizada com bloqueio de conflitos de horário, e que técnicos e coordenadores acompanhem o status de salas, laboratórios e manutenção de equipamentos em tempo real.

## 📋 Requisitos para Execução

Certifique-se de ter as seguintes ferramentas instaladas no seu ambiente de desenvolvimento antes de iniciar:

* [Node.js](https://nodejs.org/pt-br) 18+ - Inclui o gerenciador de pacotes **NPM**.
* [Git](https://git-scm.com/) - Para versionamento e clonagem do repositório.
* [Angular CLI](https://angular.io/cli) - Essencial para rodar e compilar o projeto. Pode ser instalado globalmente via terminal com o comando: `npm install -g @angular/cli`.

---

## ⚙️ Instalação das Dependências

Siga o passo a passo abaixo para clonar o repositório e configurar o ambiente local da aplicação.

#### 1. Baixar o projeto

PowerShell / CMD / GitBash:

```bash
git clone https://github.com/FATEC-AMS-PI-2026/FrontEnd-Angular-Horario
```

#### 2. Entrar na pasta do projeto

PowerShell / CMD / GitBash:

```bash
cd FrontEnd-Angular-Horario
```

#### 3. Instalar as dependências do Angular:

PowerShell / CMD / GitBash:

```bash
npm install
```

#### 4. Executar o projeto:

PowerShell / CMD / GitBash:

```bash
ng serve
```

#### Link do servidor de desenvolvimento do Angular

```text
http://localhost:4200
```

> **Nota:** O comando `ng serve` irá compilar a aplicação e iniciar um servidor web local. Abra o link acima no seu navegador para visualizar o projeto. Se preferir que o navegador abra automaticamente, você pode usar o comando `ng serve --open` (ou `ng serve -o`)
